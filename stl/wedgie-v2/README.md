# Wedgie v2 base (TEST)

**Test. Not in the print table yet.** Black. For the RP2040-Plus, no battery.

The red Atomic Wedgie base, made to hold the lid better. Fits the lids
already printed:

- Latches 6.5 wide (were 6.0) and hook 0.54 deep (was 0.5).
- The strip the lid slides over is 0.8 thicker inside on the long sides, so
  it bends less and the latches grip harder.
- RESET plunger hole, BOOT pin hole and wire slot: same as the red base.

Use one black `../atomic-wedgie/aw-reset-plunger.stl` with it.
