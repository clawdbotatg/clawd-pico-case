# Battery base (RP2040-Plus with a battery)

`base-floor-down.stl`: the v1.7 base with a 5 × 1 mm slot in the end wall
away from the USB, for the battery plug and wire. Use it with the normal lid,
joystick and buttons from `stl/current/`. Red PETG for the Atomic Wedgie,
same print settings as the case.
