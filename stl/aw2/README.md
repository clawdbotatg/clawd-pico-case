# Atomic Wedgie base v2 (RP2040-Plus with a battery)

`base-floor-down.stl`, red PETG. Battery plug slot to the top (no catch on that end), BOOT pin hole, and a hole
for a RESET button: print one more `stl/current/button.stl` in red and drop it
in from inside before the board. Lid, joystick and buttons from `stl/current/`.
