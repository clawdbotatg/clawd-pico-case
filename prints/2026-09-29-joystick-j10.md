# J10 joystick test set I–IV

Fix for the double click: a direction push clicks the direction, then a
little farther clicks the centre, because the flange edge behind the push
rises into the lid underside. The number is engraved on top of each cap.

- I: four tabs on the socket diagonals
- II: four tabs in line with the socket flats
- III: J9 full disc, riding 0.2 lower
- IV: I's tabs, riding 0.2 lower

Drop `20260929-174339-joystick-j10-plate`, no colour or GO. PETG 0.16, 4 walls,
tabs/flange down, no supports or raft. Notes ask for the parts away from the
bed centre.

Test on every device, lid on: push each direction 10 times and count the
centre clicks; also check the press-in still clicks cleanly (III/IV ride
lower). If I works and II doesn't (or the other way), that also tells which
way the stem square is turned on the board.
